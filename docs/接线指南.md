# 实验七 · 接线指南（两块板）

> 依据：固件里的引脚分配 + 《启明欣欣 407 V6.1 原理图》核对。
> 图解见 `docs/sch/`（原理图原图截图）。

---

## 一、总览

```
        ┌──────────┐   CAN 总线   ┌──────────┐
        │  板1 主控 │══Ⅴ══Ⅴ══Ⅴ═══│  板2 从机 │
        └────┬─────┘  CANH/CANL  └────┬─────┘
             │        + 共地           │
        ┌────┴────┐               ┌────┴────┐
        │SHT30    │               │SHT30    │
        │SGP30    │               │SGP30    │
        │光敏      │               │光敏      │
        │LCD·ESP  │               │LCD·ESP  │
        └─────────┘               └─────────┘
              ╲                       ╱
               ╲──────  WiFi ──────╱
                  两块板各自连 PC 热点 → 上位机
```

**只有 CAN 总线需要把两块板连起来**（一对双绞线 + 一根地线）；WiFi 是各自连 PC 热点（无线，不用接线）。

## 二、★ CAN 总线（唯一要互连的）

### 2.1 接线

| 板1 | → | 板2 |
|---|---|---|
| `1_H`（= CANH） | —— | `1_H` |
| `1_L`（= CANL） | —— | `1_L` |
| `GND` | —— | `GND`（**必须共地**）|

- 板上找 **CAN1 的 2 芯引出**（丝印 `CAN1`，在 TJA1050 `U9` 附近；原理图标 `1_H` / `1_L`）
- 用双绞线（CANH/CANL 绞在一起）最稳
- **★ 不要外接 120Ω**：每块板自带 R35=120Ω，**两块板并联 ≈60Ω —— 正好是标准值**，不用再补
  - 反过来说：**别把板上的 R35 拆掉**，也别再加第三个 120Ω

### 2.2 ★★ 两块板都要跳 P21（漏了 = 完全不通）

PA11/PA12 在板上**同时接到 USB 座**，靠 **P21**（2×3 排针）二选一：

```
        P21
USB_DM1  1 ── 2  USB_DP1     ← USB 座 J9
USB_D-   3 ── 4  USB_D+      ← MCU 的 PA11 / PA12
CAN1_RX  5 ── 6  CAN1_TX     ← TJA1050 (U9)
```

| 用途 | P21 短接 |
|---|---|
| **用 CAN1（本实验）** | ★ **3–5 和 4–6**（两个短路帽） |
| 用 USB | 1–3 和 2–4 |

> 症状对照：**程序全对、CAN 总线上却一点波形都没有** = 十有八九 P21 还停在 USB 档。
> 原理图截图：`docs/sch/p21_zoom.png`

## 三、每块板上的模块（两块板**接法完全相同**）

### 3.1 LCD（2.8″ TFT）+ 显示屏

- **直接插在板载 TFT 插座**（FSMC 接口），注意**方向**（一般有防呆缺口/丝印 1 脚）
- 不用跳线；固件已按 ILI9341 + FSMC 配好

### 3.2 SHT30（温湿度）→ I2C1

| 模块引脚 | 接到板上 |
|---|---|
| VCC | **3.3V** |
| GND | **GND** |
| SCL | **PB6** |
| SDA | **PB7** |

> ★★ **PB6/PB7 在板上没有"通用排针"，它们走的是「摄像头座 P18」**（原理图上 `PB6 = DCMI_D5`、`PB7 = DCMI_VSYNC`）。
> 摄像头是**选装**的 —— **不插摄像头，这两根就是空的**，从 P18 座上引两根线出来即可。
> 引脚对照：`DCMI_D5 = PB6 = SCL`、`DCMI_VSYNC = PB7 = SDA`。

### 3.3 SGP30（eCO₂ / TVOC／教材作"甲醛"）→ **I2C2（独立一条）**

> ★ **两个传感器各走一条 I2C** —— 每根针只对一个设备，**不需要在总线针上分叉**。

| 模块引脚 | 接到板上 |
|---|---|
| VCC | **3.3V** |
| GND | **GND** |
| SCL | **PF1**（I2C2_SCL）|
| SDA | **PF0**（I2C2_SDA）|

**PF0/PF1 在板上是空脚、且在 P7 排针上引出** —— 直接在 **P7 排针** 上找 `PF0` / `PF1` 两针接上。
（原理图确认这两个脚没有接板上任何其它器件。）

> - PF0/PF1 在板上是**空脚**（只引出到 P7 排针）✓
> - ★ 这条线**同样没有板载上拉** ⇒ **SGP30 模块必须自带 I2C 上拉**（常见模块都带）
> - **固件已切好**：`sgp30.h` 的 `SGP30_I2C_HANDLE` = **`hi2c2`**；I2C2 的引脚上拉也已在
>   `i2c.c` 的 USER CODE 里补上。详见 `CubeMX配置教程.md` §12。
> - **SGP30 上电约 15s 内是预热期**，读数不可信 —— 固件会先显示 `---`。

### 3.4 光敏模块（AO 模拟输出）→ ADC1

| 模块引脚 | 接到板上 |
|---|---|
| VCC | **3.3V** |
| GND | **GND** |
| AO | **PC0**（ADC1_IN10）|

> ★ **PC0 同样没有通用排针**：它走的是「**音乐模块 / I2S 座**」（原理图上 `PC0 = I2S_SCK`）。
> 音乐模块也是**选装**的 —— 不插它，PC0 就是空的，从那个座上引 `I2S_SCK` 那一根即可。
> 固件读 PC0 的 12 位 ADC，屏上显示为百分比。
> 若你的模块是"越亮输出电压越低"，固件里 `light.h` 的 `LIGHT_INVERT` 可翻转。

### 3.4b 如果嫌从选装座引线别扭（可选方案）

板上**通用排针**里没引出 PB6/PB7/PC0，但有别的空闲脚。想换的话需要**跑一次 CubeMX 改脚 + 重新生成**：

| 想改的 | 可换到 | 位置 | 代价 |
|---|---|---|---|
| ~~I2C~~ | ~~PB10/PB11~~ | —— | **已采用 I2C2（PF0/PF1），无需再改** |
| 光敏 | **PF3 / PF4**（ADC3_IN9 / IN14）等 | 视排针引出情况 | 要改 CubeMX（ADC1→ADC3 通道）|

> **但默认不建议改** —— 沿用实验五那套（PB6/PB7 + PC0）已经跑通过，从选装座引线即可，
> 省掉一次 CubeMX 重生成和固件适配的风险。

### 3.5 ESP-01S（WiFi）→ **串口4 WIFI 模块接口（P13）**

- 板上专用插座：**P13（`Header4*2`，2×4 排母）**，丝印"串口4WIFI模块接口"
- MCU 侧实际用到：`U4_TX = PA0`、`U4_RX = PA1`、`CH_PD`（板上已有 10K 上拉）、`VCC3.3`、`GND`
- 原理图截图：`docs/sch/wifi_socket.png`

> **★ 供电**：ESP-01S 发射瞬间要 ~300mA，**别从板上弱的 3.3V 抢** ——
> 模块 VCC-GND 之间并 **100µF 电解 + 0.1µF 瓷片**，越靠近模块越好。
> 现象：连上几秒又掉 = 十有八九是供电塌了。

### 3.6 按键 / LED

**板载，不用接线**：
- LED0/LED1/LED2（实验七：**两块板都是呼吸灯**，PE3/PE4/PG9）
- KEY0..KEY3（板1：KEY0 开始 / KEY1 停止 / KEY2 切页 / KEY3 重发 CAN；板2：KEY2 切页 / KEY3 恢复 I2C）
- 蜂鸣器（板1 超温报警）

### 3.7 ★★ 多设备怎么分叉（**同一根针只接一根线**）

板上每个信号**只有一针**。**不要在同一个针上插两根线** ——
多路分叉必须在**面包板 / 接线端子**上做。

> ★ **好消息**：两个 I2C 传感器已经分到**两条独立的 I2C**
> （SHT30 → I2C1/PB6·PB7，SGP30 → I2C2/PF0·PF1），**不再需要 I2C 分叉**。
> 剩下要分叉的只有 **供电** 和 **CAN 总线**。

| # | 哪根信号 | 要分给 | 怎么办 |
|---|---|---|---|
| 1 | **3.3V / GND** | SHT30 + SGP30 + 光敏 | 从板上取一处，在面包板上分成 3 路 |
| 2 | **CAN `1_H` / `1_L`** | 中间那块板 | 要接"进 + 出"两根线（见下） |

```
              ┌──────── 面包板（分配中心）────────┐
3.3V ─────────┬─ SHT30 VCC                       │
              ├─ SGP30 VCC                       │
              └─ 光敏  VCC                       │
GND  ─────────┴─ 三个模块 GND                    │
              └───────────────────────────────────┘

I2C 各走各的，**不用分叉**：
  PB6 / PB7   （P18 摄像头座）── SHT30
  PF0 / PF1   （P7 排针）     ── SGP30
  PC0         （P19 音乐座）  ── 光敏
```

**CAN 总线同理**（两块板"手拉手"）：

```
板1 P6 ──────── 干路 ──────── 板2 P6
         │（1根）    │            │（要 2 根）│
      H: 1 根线    H: 1 根线    H: 进+出    H: 1 根线
```

- **两端**的板：每根针只接 1 根线 ✓
- **中间**的板：`1_H` 要接"进"和"出"两根 —— **别硬塞进同一针**：
  - 用 **2 位接线端子**（每孔可夹 2 根）做干路节点，或
  - 干脆**把总线做在面包板上**：两块板各引一组线到面包板，在面包板上连成一条干路 ✓（最省事）
- 顺带：GND 也要跟着分叉（两块板共地）

> **一句话**：**板上的针只出一根线，所有分叉都在面包板/端子上做。**

## 四、上电顺序与检查清单

| # | 检查项 | 怎么确认 |
|---|---|---|
| 1 | 两块板 **P21 都跳到 CAN 档**（3–5、4–6） | 看排针上的两个短路帽 |
| 2 | CANH/CANL/GND 三根线**接牢**、**共地** | 万用表通断 |
| 3 | 两块板 **hex 没烧错** | 开机串口横幅打 `boardN`（板1→board1.hex、板2→board2.hex） |
| 4 | 三个 LCD 都插好、背光亮 | 上电即亮 |
| 5 | SHT30/SGP30/光敏 **3.3V 与 GND 没接反** | ★ 接反会烧模块 |
| 6 | ESP 模块 **CH_PD 侧有上拉**、电源加电容 | 见 3.5 |
| 7 | PC 热点已开、上位机已启动 | `python pc/upper_computer.py` |

**上电顺序不限**（板间走 CAN 广播，没有 server/client 依赖）。

## 五、接口器件位号（照着板上丝印找）

> 全部从原理图提取；**板上丝印名 = 位号**。

### 5.1 我们要用的（★ 重点）

| 丝印 / 名称 | **位号** | 规格 | 关键针 |
|---|---|---|---|
| **TFTLCD** | **J3** | 2×16 | FSMC_D0–D15 / LCD_CS / RS / RD / WR / RST / BL（第 2 页） |
| **串口4WIFI模块接口** | **P13** | 2×4 | `U4_TX`(PA0) `U4_RX`(PA1) `CH_PD` `VCC3.3` `GND` ← **ESP-01S 插这里** |
| **USB与CAN1公用IO选择** | **P21** | 2×3 | 1-2=USB座 / 3-4=**PA11·PA12** / 5-6=CAN1_RX·TX ← ★ **短接 3-5、4-6** |
| **CAN1** | **P6** | 2 针 | `1_H`(CANH) `1_L`(CANL) ← 接总线 |
| **OV2640（摄像头）** | **P18** | 2×9 | `DCMI_D5` = **PB6**、`DCMI_VSYNC` = **PB7** ← ★ **SHT30（I2C1）从这里引** |
| **引出接口**（含 URAT3/4-TTL） | **P7** | 大排针 | ★ **`PF0` / `PF1` = SGP30 的 I2C2（SDA/SCL）从这里引** |
| 串口3蓝牙模块接口 | **P16** | 6 针 | `U3_TX`=PB10 / `U3_RX`=PB11（备用；想改 I2C2 引脚可用） |
| **音乐模块接口**（WM8978 / I2S） | **P19** | 2×10 | `I2S_SCK` = **PC0** ← ★ **光敏从这里引** |

### 5.2 其它（可能用得上）

| 丝印 / 名称 | 位号 | 说明 |
|---|---|---|
| CAN2 | **P4** | 2 针（本实验不用） |
| RS485 / CAN2 引出 | **P15** | 8 针（`U2_TX`=PA2 / `U2_RX`=PA3） |
| 引出接口（URAT3-TTL / URAT4-TTL） | **P7** | 大排针（`U4_TX/RX`、`U3_TX/RX`、`PF12/13/14`、`PE7-11`、`PG0/1`…） |
| 大排针 | **P12** | 2×15（`PD0/1/5/11-15`、`PE7-15`、`PF11-15`、`PG0-5/10`…） |
| TF 卡槽 | **J8** | microSD |
| USB 座 | **J9** | USB_D-/D+（经 R63/R64 10Ω） |

### 5.3 板上芯片位号

| 位号 | 器件 | 作用 |
|---|---|---|
| **U5** | AT24C02 | I2C EEPROM（`0x50`，挂在 PB8/PB9 那条总线上） |
| **U7** | MAX485 | RS485 收发器（PA2/PA3） |
| **U9** | TJA1050 | **CAN1 收发器**（PA11/PA12，带 R35=120Ω） |
| **U11** | TJA1050 | CAN2 收发器（带 R49=120Ω） |
| U8 | 以太网 PHY | RMII（PC1/PC4/PC5…） |
| U6 | W25Q128 | SPI Flash |
