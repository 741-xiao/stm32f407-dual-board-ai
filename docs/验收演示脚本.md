## 1. ★ 上电前的三个硬检查（最容易翻车）

| # | 检查 | 症状对照 |
|---|---|---|
| 1 | **P21 短接 3–5 和 4–6**（PA11/PA12 与 USB 座二选一） | 不跳 = 程序全对，但**CAN 总线上一点波形都没有** |
| 2 | **CANH↔CANH、CANL↔CANL，两板必须共地** | 不共地 → 差分无共模参考，时通时断 |
| 3 | ★★ **两板的摆放 = 演示时的摆放**（贴在一起、CAN 线连好就别再挪） | 摆放一变，数据分布就变，模型可能当场翻车 |

> 传感器：SHT30 / SGP30 两条 I2C **都无板载上拉** ⇒ 模块必须自带；**光敏、SGP30 不要互相挨着**（SGP30 会受邻近影响）。

## 6. 按键 / 串口命令速查

### 6.1 按键（板上网络名 KEY0..KEY3；中间键 = RESET）

| | KEY0 (PF9) | KEY1 (PF8) | KEY2 (PF7) | KEY3 (PF6) |
|---|---|---|---|---|
| **板1** | **开始采集** + CAN START | **停止采集** + CAN STOP | 切 数据页/状态页 | 手动重发一次 CAN 快照 |
| **板2** | **开始采集** + CAN START | **停止采集** + CAN STOP | 切 数据页/状态页 | 手动恢复 I2C 总线 |

> ★ 两板 KEY0/KEY1 **行为完全相同**（题1 要求"按任意一板都能一起启停"）；
> 屏底提示 `KEY2:page KEY3:act`。
> **状态页**（KEY2 切过去）把 WiFi 状态机 / CAN 收发计数 / 传感器是否正常 / 对板在线 / 序号全画在屏上，
> 演示时不用连串口也能看出哪个环节出问题。

### 6.2 串口命令（USART1 115200-8-N-1，单字符 + 回车）

| 键 | 作用 |
|---|---|
| `?` | 命令帮助 |
| `l` | 读光敏（raw / avg / pct） |
| `t` | 读一次 SHT30 |
| `g` | 读一次 SGP30（eCO₂ / TVOC） |
| `s` | 状态：运行/序号/温湿/eCO₂/TVOC/WiFi/CAN 收发计数 **+ AI 判定** |
| `w` | WiFi 状态机（含 5 类重连原因计数，排错用） |
| `c` | **CAN 自测**：发一帧心跳（查总线通不通） |
| **`a <C>`** | **报警阈值**（**只有板1 有效**，板2 敲了不变）：默认已是 35℃，平时不用敲；演示"超温报警"时 `a 28` 立刻触发，完事 `a 35` 恢复 |
| **`n`** | ★ **题2 演示**：把 `ai_test10.h` 那 10 条留出样本逐条推理，打印 `判定/置信度/真值/对错` |

## 7. 故障速查

| 现象 | 原因 / 处理 |
|---|---|
| CAN 上毫无波形 / 板2 收不到数据 | ★★ **P21 没短接 3–5、4–6**（最常见）→ 再查共地 → 两板都 500kbps |
| 板1 屏对板状态一直**错误** | 板2 没上电 / CAN 断 / 波特率不符 |
| 网页连上但**一个字节都没有** | 板端 WiFi 状态机没到 READY（看状态页或串口 `w`） |
| 库里没数据 | `[DB] 未启用` → 没装 pymysql / 没写 `pc\db_local.py` / 表没建 |
| 两板 CO₂/TVOC 显示 `---` | SGP30 **暖机中**（上电约 15s 内正常）；15s 后仍 `---` → I2C 没接好（`g` 查） |
| 网页图看不出两块板 | 确认 `S` 帧到了（状态条在动）；假板/真板都行 |
| **重训后板上判定没变 / 明显错** | ★ 忘了跑 `python tools\gen_ai_code.py` → 板上是"新归一化 + 旧权重"。先 `check_sync.py` 自检 |
| 编译报 `cannot open source input file "ai_model.h"` | `firmware.uvprojx` 被 `git checkout --` 回滚掉了 AI 文件组 → 重跑 `python tools\make_project.py firmware` |
| 改了 PC 代码没生效 | 旧 python 进程没退：`Get-NetTCPConnection -State Listen -LocalPort 8000` 找 PID → `Stop-Process` |
| 板1 一直报警 | 环境温度 > 阈值（默认 35℃）：串口 `a 40` 再调高；或检查是不是手/笔记本出风口一直烤着传感器 |
