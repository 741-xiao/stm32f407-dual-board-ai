## 常见问题

| 情况 | 处理 |
|---|---|
| 网页一直不动 | 检查 PC 热点、两板 WiFi 是否连上（串口敲 `w` 看重连原因），以及防火墙是否放行 8080/8000 |
| 板 2 屏上「板 1 区」不刷新 | CAN 没通：查 P21 跳线、双绞线 A/B 是否接反 |
| CO₂/TVOC 显示 400 / 0 | SGP30 还在暖机，开录前先让板子跑 15 秒 |
| 判定忽然变成未推理 | 板子刚重启，等第一条上报即可；或检查是否烧的是最新 hex（`tools/check_sync.py --hex`） |
