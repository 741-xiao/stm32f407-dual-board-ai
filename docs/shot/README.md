## 命名要求

- 一律 **`S<编号>.png`**（大写 S，两位内数字），与上表一致，否则报告里是破图。
- 手机拍的照片建议先裁掉无关背景、保证**文字可辨认**（尤其 LCD 和串口窗口）。
- 分辨率不必很大，宽度 1000~1600 px 足够，避免文档体积过大。
